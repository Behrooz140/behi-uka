# UKA 6.0 — ساخت behi

[مستندات انگلیسی (پیشفرض)](README.md)

`behi_uka` بازسازی نگهداریشده از ماژول **Unpacker Kitchen for Android (UKA)** نسخه 5.39 است؛
نسخهای که در اصل توسط **kory-vadim** نوشته و توسط **@Aadez007** به انگلیسی ترجمه شد.
چون پروژه اصلی دیگه آپدیت نمیشود، این فورک ابزارهای داخلی رو به نسخههای جدیدتر ارتقا داده
در حالی که تمام مسیرها، نام دستورها و رفتار منو دقیقاً مثل قبل باقی ماندهاند.

## قابلیتها

- استخراج و بستهبندی `boot.img` / `recovery.img` (از طریق AIK-mobile داخلی)
- استخراج، ویرایش و بستهبندی `system.img`, `vendor.img`, `super.img` و سایر پارتیشنها
- تبدیل بین فرمتهای `raw`, `sparse`, `.dat` و `.br` (brotli)
- کار با بستههای OTA به نام `payload.bin` و ایمیجهای تقسیمشده Qfil کوالکام
- پشتیبانی از فایل سیستمهای ext4، EROFS و F2FS
- استخراج `file_contexts` و تبدیل `file_contexts.bin` روی دستگاه
- ساخت ایمیج super با `lpmake` از AOSP

همه کارها **روی گوشی** و از طریق ترمینال انجام میشود.

## نصب

1. [Magisk](https://github.com/topjohnwu/Magisk) رو نصب کن.
2. فایل `behi_uka_6.0_Magisk_arm64.zip` رو از Magisk → Modules → Install from storage فلش کن.
3. ریبوت کن.

> شناسه ماژول `behi_uka` است، پس میشود آنرا کنار ماژول اصلی `UKA` نصب کرد بدون تداخل id.
> هر دو ماژول از یکسان مسیرهای `/data/local/...` استفاده میکنند، بنابراین آنها رو همزمان اجرا نکن.

## استفاده

ترمینال گوشی رو باز کن:

```sh
su

```

`6.0` / `behi build` و شناسه ماژول مورد استفاده توسط uninstaller است.

## بازسازی از سورس

روی هر لینوکسی:

```sh
./build.sh
```

خروجی در `out/behi_uka_6.0_Magisk_arm64.zip` قرار میگیرد.

## نکات سازگاری

`mkfs.erofs` و `extract.erofs64` فورک سفاری UKA/Rosenbergاند و فلگهای
`--only-cfg`, `--product-out`, `-E^xattr-name-filter` رو درک میکنند؛ جایگزینیشون با
upstream زنجیره unpack→repack رو میشکند. همینطور `make_ext4fs`, `e2fsdroid`, ابزارهای
AOSP partition، AIK-mobile 3.8 و پایتون 3.11 داخلی (با ۸۴ ماژول کامپایلشده cpython-311)
عمداً دستنخورده ماندند.
